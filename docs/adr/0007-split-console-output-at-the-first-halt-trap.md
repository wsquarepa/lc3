# Split console output at the first HALT trap or halt-routine entry

Halt output begins at whichever comes first: the first executed `TRAP x25` (word xF025), or the first fetch of an instruction at the halt-routine address, defined as the word stored at x0025 when the run starts, after case pokes are applied and before the first instruction. Everything written before that point is program output. The halt-routine address is captured once per run, before triggers, and does not change with later writes to x0025. Cutting `lc3sim` output at the reference OS's `--- halting the LC-3 ---` text does not generalize, because the halt text varies by OS (the bundled OS shortens it), so the split is by mechanism rather than by string. The second trigger is necessary because the reference OS's undefined-trap routine prints its message and then branches into its halt routine without executing `TRAP x25`. A direct JSR into the halt-routine address also starts halt output there. A run that halts by writing the machine control register directly, without either event, has empty halt output.
